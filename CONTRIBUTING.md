# Contribuir a Retorna

Gracias por colaborar. Este repositorio está preparado para trabajo coordinado entre personas y agentes de IA.

Antes de comenzar:

1. Lee [`AGENTS.md`](AGENTS.md).
2. Revisa [`docs/PROGRESS.md`](docs/PROGRESS.md).
3. Toma una tarea libre en [`docs/TASKS.md`](docs/TASKS.md).
4. Sigue [`docs/GITFLOW.md`](docs/GITFLOW.md) y [`docs/CONVENTIONAL_COMMITS.md`](docs/CONVENTIONAL_COMMITS.md).

Ningún cambio está completo sin actualizar el tracking obligatorio. Usa [el playbook](docs/AGENT_PLAYBOOK.md) y el template de pull request.
